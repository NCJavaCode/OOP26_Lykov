# OOP26_Lykov

## Опис роботи

У цій практичній роботі я створив декілька класів на мові Java та попрацював з об'єктами для системи онлайн-кінотеатру.

Було створено класи `Movie` та `Cinema`.

У класах я повністю реалізував принцип **інкапсуляції**. Усі поля класу зроблені `private`, щоб захистити дані від прямого некоректного втручання ззовні. Для доступу та зміни даних використовуються спеціальні методи (гетери та сетери), а в сетері `setAgeRestriction()` додано логіку контролю значень.

---

## Створені класи

* `Movie` — клас для опису фільму (назва, тривалість, вікове обмеження). Містить контроль вхідних даних для вікового обмеження
* `Cinema` — клас для опису кінотеатру (назва, адреса).

---

## Що я зробив

* створив структуровані класи для предметної області;
* додав приватні поля та публічні методи доступу;
* використав модифікатори доступу (`private`, `public`);
